# EARPMS v6 fixes

- Added class-level enrollment presentation and Select Entire Class for eligible active pupils.
- Active Answer Scripts & AI Marking Queue now excludes examiner-approved/finalized scripts; finalized scripts leave the queue.
- Added Prev/Next navigation for pending scripts.
- Added bulk finalization of all eligible examination result sets on Results & Rankings.
- Added role-specific dashboard workflow activity showing teacher submission notes and principal feedback/actions.
- Fixed Report Cards Prev/Next synchronization when session/term changes.
- Added persisted report-card ranking refresh using finalized results only, with competition ranking and correct total participating pupils.
- Report-card generation now ranks only pupils with finalized results and no longer hard-codes class position.
- Existing report cards can be refreshed to correct stale positions.
- Bulk regenerated-paper preview remains available as one continuous scrollable preview.
